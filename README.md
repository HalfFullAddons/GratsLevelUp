# Grats! Level Up

A Warcraft-style celebration every time you ding. Unofficial fan tool, World of Warcraft is a trademark of Blizzard.

**What you see when you level up (out of combat)**
1. **Intro**: a big GRATS!, then "You have reached Level 24", your race, class and faction. Milestones (10, 20, 30, 40, 50, 60) get a longer intro and a banner line.
2. **Stronger Than Before**: health, rage/mana/energy, stats and talent points you just gained.
3. **New Training Available**: the class spells you can now learn, with icons, ranks, costs, a total and your gold. Spells from class quests are marked "Class quest".
4. **New Roads Open**: zones, dungeons, battlegrounds and raids you just reached the level for (your faction only).

Empty pages are skipped. Use Back to revisit a page. The review fades away on its own a few seconds after it finishes (hover it to keep it open). Grats! replaces the game's own level-up chat lines and centre-screen text (both can be turned back on).

**In combat** the review opens straight away as a see-through watermark, so it never blocks the fight. You can click through the page, and Skip, Back and Next still work. It turns solid and plays through when combat ends.

**Battlegrounds**: strip only; the full review plays after you leave (option).

**Options** (`/gratz`, or Interface > AddOns): theme (My race, any race frame, Parchment, Dark, Class colours, Faction colours), race atmosphere, level-up sound, celebration (Full, Quick, Strip only), position (right beside the quest tracker, left, center, or drag anywhere), size and scale, opacity, sounds, race music interlude, lowering game music, chat lines, strip lock, minimap button, newer-version notice.

**Commands**: `/gratz` options · `/gratz replay [1-5]` (this character) · `/gratz test [level]` · `/gratz strip` · `/gratz reset` · `/gratz error` (last error, if any). `/grats` also works if no other addon uses it. Keybindings: Replay last level-up, Open options.

**Works with**
- **What's Training?**: if installed, Grats! uses its live training data (respects its ignore list and faction discounts). Without it, Grats! uses its own built-in table for all 9 classes.
- **Bar Check**: if installed, the last page shows a "View my Bar Check card" button.
